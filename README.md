# Retail Sales Analysis using PostgreSQL + Power BI

## Project Overview

This project focuses on analyzing retail sales data using PostgreSQL and visualizing business insights using Power BI. The objective is to identify profitable categories, top customers, payment preferences, regional performance, and product-level profitability to support better business decision-making.

The dataset was imported from a CSV file into PostgreSQL, where SQL queries were used to analyze category-wise sales, region-wise profits, customer purchasing behavior, monthly sales trends, and loss-making products. Power BI was then used to create a single-page interactive dashboard for clear business reporting and visualization.

## Key Business Insights

* Office Supplies generated the highest total sales among all categories
* West region recorded the highest total profit compared to other regions
* Cash on Delivery (COD) was the most preferred payment mode
* Some high-sales products generated losses due to poor profit margins
* Premium office equipment and technology products contributed the highest revenue
* Monthly sales showed demand spikes during specific periods
